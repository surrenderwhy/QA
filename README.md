# Учебный проект Айман: неделя 3

Это стартовая настройка, а не готовое решение. Метод расчёта пока пустой, тесты доставки нужно написать самостоятельно.

1. Распакуй архив в отдельную папку и открой pom.xml в IntelliJ IDEA как Maven-проект.
2. Используй установленный JDK не ниже 17; для этого учебного проекта язык компилируется как Java 17. В IDEA выполни Reload All Maven Projects и дождись загрузки зависимостей.
3. Запусти SetupSmokeTest кнопкой рядом с тестом. Он проверяет только настройку JUnit, не расчёт доставки.
4. В понедельник заполни calculateDelivery по требованиям V2 из таблицы. Сохрани старые принятые исходники отдельно.
5. В среду добавь свои @Test в DeliveryCalculatorTest. Используй assertEquals: сначала ожидание, затем вызов метода.
6. Тесты лежат в src/test/java, рабочий код в src/main/java. Проверяй, что запускаются именно тесты доставки, а не только SetupSmokeTest.
7. Для запуска всех тестов используй Maven → Lifecycle → test в IDEA. Если Maven установлен в терминале, можно выполнить mvn test.
8. Не коммить папки target, out и .idea. В архив уже включён .gitignore.

Зависимости закреплены: JUnit Jupiter 5.10.2. Изучать Maven целиком на этой неделе не требуется. Если настройка не заработала за 15 минут, отправь точный текст ошибки.
