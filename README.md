# Программа DeliveryCalculator

Программа разработана для расчета итоговой стоимости доставки на основе суммы заказа, расстояния и выбора экспресс-доставки:

Базовая стоимость:

1)Если сумма заказа от 0 до 2999 рублей — доставка стоит 250 рублей.

2)Если сумма заказа от 3000 рублей и выше — доставка бесплатная (0 рублей).

Наценка за расстояние: Если расстояние больше 20 км, к стоимости добавляется 150 рублей.

Наценка за экспресс: Если выбрана экспресс-доставка (express === true), к стоимости добавляется 200 рублей.

Если пользователь введет отрицательную сумму - выйдет сообщение: "Сумма не может быть отрицательной"

Если расстояние меньше 1 км или больше 100 км — выбрасывается ошибка: *"Расстояние должно быть от 1 до 100 км"

# Пройденные тест-кейсы
Параметризованный тесты (12 кейсов)

С помощью @ParameterizedTest и @CsvSource проверяется корректность расчетов при различных комбинациях:

Граничные суммы: 2999 (платная доставка) и 3000 (бесплатная).

Граничные расстояния: 20 км (без наценки) и 21 км (с наценкой 150 руб).

Экспресс-доставка: true (наценка 200 руб) и false.

Минимальные допустимые значения: расстояние 1 км и 100 км, сумма 0 руб.

Тесты на исключения (assertThrows)

Проверяется, что программа корректно «падает» и выдает нужный текст ошибки при неверных данных:

1)Отрицательная сумма заказа 

2)Расстояние меньше 1 км 

3)Расстояние больше 100 км 

4)Комбинация неверных данных 

# Как запустить тесты через IDEA/Maven

Для запуска всех тестов используется Maven → Lifecycle → test в IDEA. Если Maven установлен в терминале, можно выполнить mvn test
